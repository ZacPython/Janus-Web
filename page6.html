Third-party Training Courses

CS50's Web Programming with Python and JavaScript

CS50's Web Programming with Python and JavaScript is an advanced web development course created by Harvard University. The course builds upon basic programming knowledge and introduces students to the technologies used to create modern websites and web applications. Learners gain experience with HTML, CSS, JavaScript, Python, Django, SQL databases, APIs, Git, testing, and continuous integration. Throughout the course, students complete practical projects that simulate real-world development scenarios, helping them build a portfolio of work. By the end of the course, learners will understand both front-end and back-end development and how different technologies work together to create fully functional web applications.

Codecademy Full-Stack Engineer Career Path

The Codecademy Full-Stack Engineer Career Path is designed for beginners who want to become professional web developers. The course provides step-by-step training in front-end technologies such as HTML, CSS, JavaScript, and React, before moving on to back-end development with Node.js, Express, and SQL databases. Students learn how to design responsive websites, create APIs, manage databases, use version control with Git and GitHub, and deploy applications to the web. The programme includes hands-on projects and portfolio-building activities that allow learners to demonstrate their skills to potential employers. Its interactive learning environment makes it particularly suitable for self-study and remote learning.

CompTIA Security+

CompTIA Security+ is one of the most widely recognised entry-level cybersecurity certifications in the industry. The course provides a strong foundation in essential cybersecurity concepts, including network security, risk management, cryptography, identity and access management, threat detection, vulnerability assessment, and incident response. Learners develop an understanding of how organisations protect their systems and data from cyber threats and how security professionals identify and respond to attacks. The certification is vendor-neutral, meaning the skills learned can be applied across a wide range of technologies and workplaces. Security+ is frequently requested by employers and is often considered a starting point for careers in cybersecurity, IT support, and network administration.

Cisco Networking Academy – Introduction to Cybersecurity

Cisco's Introduction to Cybersecurity course provides a comprehensive overview of the cybersecurity field and is ideal for beginners with little or no previous experience. The course explores common cyber threats such as malware, phishing attacks, ransomware, and social engineering techniques while explaining how organisations protect their networks, devices, and sensitive information. Learners are introduced to fundamental security principles, digital privacy, online safety practices, and the importance of cybersecurity in modern businesses. The course also highlights various career pathways within the cybersecurity industry, helping students understand the skills and qualifications required for different roles. Upon completion, learners receive a certificate that can be added to their CV or professional portfolio.
