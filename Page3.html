Trainee Web Developer

Essential Requirements
  • Basic understanding of HTML and CSS
  • Good communication and teamwork skills
  • Willingness to learn new web technologies
  • Ability to work independently and meet deadlines
  • Passion for web development and design

Preferred Qualifications
  • Experience creating simple websites or personal projects
  • Basic knowledge of JavaScript
  • Familiarity with VS Code or GitHub
  • Understanding of responsive web design
  • GCSEs or equivalent qualifications in IT or Computing

  • Basic understanding of computer systems and networks

  • Good communication and teamwork skills
  • Willingness to learn cyber security tools and techniques
  • Interest in online safety and technology
